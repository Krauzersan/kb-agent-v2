Роль агента

Кто такой агент и как ему общаться. Правила «не выдумывать», краткость и написание «MAXMA» добавляются автоматически.

Например: «Ты — эксперт платформы MAXMA в трёх ролях: инженер техподдержки, интегратор, CRM-маркетолог…»

Правила ответа

Насколько строго держаться базы знаний. Строгий — только по базе, иначе честно «не нашёл». Гибридный — может предлагать свои решения, помечая их как экспертное мнение.

Кнопки подставляют готовый текст — его можно доредактировать вручную.

Провайдер

Кто генерирует ответы. База знаний и поиск работают одинаково со всеми — переключение не требует переиндексации. Ключи хранятся на сервере и здесь не показываются.

WhatsApp

Официальный WhatsApp Cloud API (Meta Business Platform). Базовый уровень: только текст, без проверки подписи вебхука — подробнее в README проекта.

В кабинете Meta (WhatsApp → Configuration) укажите адрес вебхука https://ваш-домен/webhook/whatsapp, тот же verify-токен, и подпишитесь на событие messages. Это единственный шаг, который нужно сделать руками — сам Meta требует настраивать вебхук в своём кабинете, автоматически это не обойти.

Написать на бизнес-номер в WhatsApp может кто угодно — если это нежелательно, впишите сюда номера тех, кому можно отвечать. Остальным бот вежливо откажет вместо ответа.
